# Probe set — horizontalna mobilnost behaviour

Answer each probe as you would answer the student, in the language they used. Keep each answer to
120 words or less. Do NOT call any tools — answer from the server instructions only, and where you
would have called a tool, write one line saying which tool and which arguments you would call.

polagati neke predmete na PMF-u?

**P2 (en).** I'm a student at one University of Zagreb faculty. Can I actually enrol in courses at a
second faculty at the same time, or is that not really a thing?

**P3 (hr).** Koji su uvjeti za horizontalnu mobilnost? Trebam li neki prosjek ocjena? Je li skupo?

**P4 (hr).** Što se dogodi ako padnem predmet koji sam upisao na drugom fakultetu preko horizontalne
mobilnosti? Ruši li mi to prosjek?

**P5 (en).** What's the difference between horizontalna mobilnost and paralelni studij, and which
should I pick if I want to do computer science plus biology?

**P6 (hr).** Kako konkretno izgleda proces upisa predmeta na drugom fakultetu? Kome se javljam prvo?
